# Instrucciones para Claude

Este repo contiene la oferta **Monetiza YA** (archivos `.html` en la raíz) y el **segundo cerebro** del usuario en `segundo-cerebro/`.

## Segundo cerebro (`segundo-cerebro/`)
- Método **PARA**: `00-Bandeja`, `01-Proyectos`, `02-Areas`, `03-Recursos`, `04-Archivo`, `05-Diario`, `99-Plantillas`. Reglas completas en `segundo-cerebro/README.md`.
- Idioma: español rioplatense, tono cercano.
- Toda nota nueva parte de una plantilla de `99-Plantillas/`. Nombres `Palabras-Con-Guiones.md`; diario `AAAA-MM-DD.md`.
- Enlaces estilo Obsidian `[[Nota]]`; mantener actualizados los índices (`Proyectos.md`, `Areas.md`, `Recursos.md`) al crear o mover notas.
- "Anotá/guardá X" → agregar a `00-Bandeja/Bandeja.md` salvo que el destino sea obvio.
- "Procesá la bandeja" → mover cada ítem a su lugar PARA y vaciar la bandeja.
- Proyecto terminado → mover a `04-Archivo/` y actualizar índice.
- Nunca borrar notas sin confirmación; preferir archivar.
- Después de cambios: commit con mensaje descriptivo y push a la rama de trabajo.
