Función 01
Crear Presencia Básica
Plataformas para tener un perfil profesional sin web propia
🔗
Linktree
Página de enlaces
GRATIS
Una sola URL que agrupa todos tus canales, oferta y forma de contacto. Reemplaza una web completa para quien recién empieza. Funciona como tu "sede digital" provisional.
Cuándo usarlo
Desde el día 1, antes de tener cualquier otra plataforma
Configuración mínima
Foto, nombre, 1 frase de propuesta, link de oferta o contacto
⚙️ Setup en 15 minutos
Crea cuenta → sube foto → agrega título con tu propuesta de valor → añade máximo 3 links (oferta, WhatsApp o email, red principal) → comparte esa URL en tu bio de Instagram o LinkedIn.
💼
LinkedIn (perfil optimizado)
Red profesional
GRATIS
Un perfil de LinkedIn bien configurado funciona como CV, landing page y canal de contacto al mismo tiempo. Ideal para posicionarte frente a clientes B2B o de servicios.
Cuándo usarlo
Si tu cliente ideal es profesional, empresa o freelancer
Configuración mínima
Foto profesional, titular con resultado que ofreces, sección "Acerca de" con tu propuesta
⚙️ Setup esencial
Titular: "Ayudo a [QUIÉN] a [RESULTADO] sin [OBSTÁCULO]" → Acerca de: 3 párrafos (problema que resuelves, cómo lo haces, a quién ayudas) → Agrega tu link de Linktree o WhatsApp Business en contacto.

Función 02
Validar Oferta
Herramientas para testear interés real antes de crear el producto
📋
Google Forms
Formularios y encuestas
GRATIS
Crea una encuesta de validación de 3 a 5 preguntas para medir si tu audiencia pagaría por tu oferta antes de construirla. Simple, rápido y con respuestas automáticas en hoja de cálculo.
Cuándo usarlo
Antes de crear cualquier producto. Valida primero, construye después.
Configuración mínima
5 preguntas: problema, intentos previos, disposición a pagar, precio, email de contacto
⚙️ Las 5 preguntas clave
1. ¿Cuál es tu mayor dificultad con [tema]? 2. ¿Ya intentaste resolverlo? ¿Cómo? 3. Si existiera una solución para esto, ¿la comprarías? 4. ¿Cuánto pagarías? 5. ¿Quieres que te avise cuando esté lista? (email)
💬
WhatsApp Business
Validación directa
GRATIS
La herramienta de validación más subestimada. Un mensaje directo a 10 contactos relevantes genera más datos reales que cualquier encuesta. Si 3 dicen "¿cuándo lo lanzas?", tienes validación.
Cuándo usarlo
Como primer paso antes de cualquier publicación pública
Configuración mínima
Perfil de negocio + mensaje de validación + respuestas rápidas configuradas
⚙️ Mensaje de validación listo
"Hola [nombre], estoy creando algo para ayudar a [perfil] a [resultado]. ¿Es algo que te haría falta ahora? Te cuento más si te interesa." → Con 5+ "sí" tienes luz verde para construir.

Función 03
Cobrar
Opciones simples para recibir pagos desde el día uno
🟠
Hotmart
Plataforma de infoproductos
GRATIS para empezar
Plataforma líder en Latinoamérica para vender productos digitales. Maneja el cobro, la entrega del archivo y la facturación automáticamente. Cobra comisión solo cuando vendes.
Cuándo usarlo
Para vender PDFs, mini-cursos, plantillas o cualquier producto digital
Comisión
9.9% + tarifa fija por venta. Sin mensualidad ni costo de alta.
⚙️ Setup en 30 minutos
Crea cuenta → completa datos fiscales → crea producto (sube PDF o acceso) → define precio → activa página de pago → comparte el link. Listo para vender.
🟣
Gumroad
Venta directa de digitales
GRATIS
Alternativa internacional, ideal si tienes audiencia fuera de Latinoamérica o quieres cobrar en USD. Permite crear páginas de producto simples en minutos y aceptar tarjetas de todo el mundo.
Cuándo usarlo
Si cobras en USD o tienes audiencia internacional
Comisión
10% por venta. Sin costo mensual. Paga directo a tu cuenta.
⚙️ Setup en 20 minutos
Crea cuenta → New Product → sube archivo → escribe descripción y precio → publica → comparte link. Acepta pagos con tarjeta de crédito en más de 190 países.
💸
Mercado Pago / Transferencia
Cobro directo
GRATIS
Para servicios directos o preventa, no necesitas plataformas. Un link de pago de Mercado Pago o una transferencia bancaria directa es suficiente para cobrar tu primera venta hoy.
Cuándo usarlo
Para servicios express, sesiones, validación pagada o preventa
Comisión
Varía por país. Transferencias bancarias: sin costo en la mayoría de los casos.
⚙️ Setup inmediato
Crea tu link de cobro en Mercado Pago (Cobrar → Link de pago → define monto y descripción) → comparte por WhatsApp. Para servicios: acuerda precio, comparte datos bancarios, confirma pago antes de entregar.

Función 04
Organizarse
Recursos para gestionar clientes, tareas y tiempos sin complicaciones
⬛
Notion
Base de operaciones
GRATIS
Tu sistema operativo personal. Úsalo para centralizar clientes, tareas, ideas, borradores de oferta y seguimiento de ventas. Una sola herramienta reemplaza CRM, agenda y bloc de notas.
Cuándo usarlo
Desde el inicio para no perder información ni dispersar el foco
Configuración mínima
3 páginas: Mis ofertas activas · Mis clientes · Tareas de la semana
⚙️ Setup mínimo
Crea workspace → añade página "Clientes" (tabla con nombre, estado, próximo paso) → página "Ofertas" (nombre, precio, canal) → página "Plan semanal" (lunes a viernes con 1 tarea diaria monetizable). No sobrediseñes.
📅
Google Calendar
Gestión de tiempo
GRATIS
Para quien ofrece sesiones o servicios con entrega en fecha, un calendario compartido elimina el caos de coordinar horarios por mensajes. Calendly (gratis básico) lo conecta y automatiza.
Cuándo usarlo
Cuando tienes más de 2 clientes activos o sesiones que coordinar
Configuración mínima
Bloquea horarios de trabajo + conecta con Calendly para que el cliente elija su hora solo
⚙️ Flujo recomendado
Google Calendar (bloquea tu disponibilidad) → Calendly gratuito (crea evento de 60 min) → comparte el link de Calendly cuando alguien quiera una sesión → eliminas el ping-pong de "¿cuándo puedes?"

Función 05
Producir Contenido Simple
Apps para crear piezas de contenido sin diseño profesional
🎨
Canva
Diseño visual
GRATIS
Diseña publicaciones, portadas de productos, plantillas editables y carruseles sin saber de diseño. La versión gratuita cubre el 90% de lo que necesitas al inicio.
Cuándo usarlo
Para crear cualquier pieza visual: oferta, post, portada de PDF, checklist
Configuración mínima
Elige 1 paleta de colores + 1 tipografía + crea plantilla base reutilizable
⚙️ Kit visual mínimo
Crea 3 plantillas base: 1 post cuadrado (oferta/contenido) + 1 historia vertical (CTA) + 1 portada de PDF (para tu producto). Guárdalas y reutiliza cambiando solo el texto.
🎙️
CapCut
Edición de video
GRATIS
Para quienes quieren crear reels, shorts o videos de oferta sin curva de aprendizaje. Tiene subtítulos automáticos, plantillas y edición por voz. Resultado profesional en minutos.
Cuándo usarlo
Cuando quieras añadir video corto como canal de contenido o presentación de oferta
Configuración mínima
Activa subtítulos automáticos + elige plantilla de texto → graba en vertical → exporta a 1080p
⚙️ Video de oferta en 20 minutos
Graba 60–90 seg hablando de tu oferta (problema → solución → precio → cómo contratar) → importa a CapCut → activa subtítulos → ajusta cortes → exporta. Sin música ni efectos: el mensaje es suficiente.

🚫 Errores tecnológicos que frenan el inicio
Esperar a tener una web propia antes de ofrecer. Un link de WhatsApp + Linktree es suficiente para vender.
Instalar 10 herramientas "por si acaso". Más setup = más distracción. Activa solo lo que vas a usar esta semana.
Buscar la plataforma perfecta. La plataforma correcta es la que te permite cobrar hoy. Lo demás viene después.
Pagar suscripciones antes de tener ingresos. Todo lo de este kit es gratuito. Si necesitas pagar, es porque ya estás vendiendo.
Pasar más tiempo configurando que vendiendo. El setup máximo para empezar: 2 horas. Después, a ejecutar.
