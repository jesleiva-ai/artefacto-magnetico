# Cómo usar tu Segundo Cerebro

Sistema de notas en Markdown, organizado con el **método PARA** (Tiago Forte).
Se puede abrir con [Obsidian](https://obsidian.md) (abrí la carpeta `segundo-cerebro/` como bóveda) o leer directo en GitHub.

## El flujo: Capturar → Organizar → Destilar → Expresar
1. **Capturar**: todo lo nuevo va a `00-Bandeja/Bandeja.md` (o un archivo nuevo dentro de `00-Bandeja/`). Sin pensar dónde va.
2. **Organizar**: en la revisión semanal, mové cada cosa a su lugar:
   - ¿Tiene objetivo y fecha? → `01-Proyectos/`
   - ¿Es algo que mantengo siempre? → `02-Areas/`
   - ¿Es conocimiento útil? → `03-Recursos/`
   - ¿Ya no sirve / terminó? → `04-Archivo/`
3. **Destilar**: resaltá lo importante y escribí un resumen de 2–3 líneas arriba de cada nota.
4. **Expresar**: convertí notas en cosas reales: un bono, un anuncio, un post, una decisión.

## Convenciones
- Nombres de archivo: `Palabras-Con-Guiones.md`. Diario: `AAAA-MM-DD.md`.
- Enlaces entre notas: `[[Nombre-de-la-nota]]`.
- Etiquetas: `#idea`, `#accion`, `#aprendizaje`, `#contenido`, `#meta-ads`, `#oferta`.
- Cada nota nueva arranca desde una plantilla de `99-Plantillas/`.
